High-performance Roblox aimbot focused on adaptive smooth tracking and precise auto aim.

---

## 🎯 What it is

**Roblox Aimbot** is a client-side script that provides adaptive auto aim and smooth target tracking.  
It is designed to be lightweight, easy to configure and work with the majority of modern executors.

> ⚠️  
> Use at your own risk. This is an open-source educational project.

## ✨ Features

| Feature                  | Description                                      |
|--------------------------|--------------------------------------------------|
| 🎯 **Adaptive Auto Aim** | Smooth and precise target locking                |

---

## 🧩 How to use

1. Join any Roblox game.  
2. Execute `main.lua` with your executor.  
3. Open the UI and configure settings.  
4. Hold or toggle the aim key.

---

## ⚙️ Configuration

All settings can be changed in the UI or in `config/default.json`:

- Aim smoothness  
- FOV size  
- Target priority  
- Team check  
- Visibility check  
- Hotkeys
